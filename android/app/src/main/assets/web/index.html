Esc
暂停或继续

借掩体绕侧或撤退：坦克不能穿过，弹丸碰到掩体会消失。每辆坦克有3发弹仓，射击间隔0.65秒，缺弹时每0.85秒自动恢复一发；边开火边恢复，打空后也可以停火攒弹。敌车上方的小格显示它的剩余弹药。

淡色场景仅作背景，石块才会阻挡坦克和弹丸；暂停时可以关闭场景背景。

难度影响机器人的反应与瞄准。它们有追击、游走、谨慎等不同偏好；基础生命、伤害、速度、弹仓和视野相同。

开启公共补给后，场上会提前3秒预告位置。经过补给即可拾取，移动速度提高25%，持续7秒；双方都能争夺，不回复生命或护甲。开局可取消勾选，体验无补给对局。

移动一段距离，留下一枚墨斑；停下不落墨，后色覆盖前色。射击只用于攻击。敌色弹丸命中后消失；弹丸之间互相穿过。走过旧痕迹不会受伤。

伤害先扣护甲，再扣生命。护甲不可恢复；自己的颜色面积越多，生命恢复越快，收益逐渐减小并有上限。

每局最多10分钟，最后存活者立即获胜；全灭或时间到，按最终面积判胜。战亡不额外落墨。结束后，本局墨斑会尝试组成一件立体作品，可旋转欣赏、查看原画和保存；成形不理想时仍可保留原画、重试或再来一局。
