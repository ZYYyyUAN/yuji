# 素材来源

本文件仅记录素材来源；玩家界面不展示工程说明。

- assets/room.png：项目既有AI插画，来自雨停之后_街区体验/assets/tea-clean.png。该图为旧茶店背景的空桌编辑版，本轮直接复制，没有再次生成或编辑。原提示词记录在同目录美术资产与最终提示词.md。
- assets/paper.wav：来自项目既有纸张程序建模音效，原文件雨停之后_声效/paper.wav；不是纸张现场录音。
- assets/wood.wav：原wood-recorded-v1.wav，组合并处理两项真实录音：Yoyodaman234的[Bamboo Creaking in Wind](https://freesound.org/people/Yoyodaman234/sounds/335891/)，以及abstraktgeneriert的[Sticks.wav](https://freesound.org/people/abstraktgeneriert/sounds/348959/)。原项目记录两者许可为[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)，采用公开HQ MP3试听源。处理为短摩擦与轻碰组合、过滤与电平控制；本轮文件原样复制。它是木竹拟音，不是坦克动作实录。
- 开火、受伤、移动的轻音效：本轮Web Audio运行时合成；无外部声音服务。
- 坦克、墨斑、作品：项目既有Canvas/SVG和实际对局数据，未将场景图片绘入作品导出。

原文件、旧提示词与声音来源记录保留在项目中。本包未接入在线图像生成。
