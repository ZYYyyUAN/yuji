# 《余迹》AI与第三方素材说明

对应参赛候选0.21.0 / 21。用于转存为主办方要求的在线说明文档。

## AI使用范围

本游戏内含有使用 AI 生成的游戏资产。

三张包内场景图courtyard.png、lane.png、room.png，均为本项目2026年10月开发期间生成/编辑的AI插画，使用OpenAI image_gen工具，分别呈现院落、南巷与茶店。背景图3张中3张为AI生成，即该类别按文件数为100%；这是类别统计，不是自行认定官方综合占比口径。

AI背景用于首页、暂停和半透明战场环境。它们不进入原画导出、面积统计或立体墨斑数据。旧版本复用指本次同一开发项目内早先生成的资产；不宣称人工绘制。

坦克、掩体、弹丸、墨斑、补给、按钮、图标与结算由Canvas/SVG/CSS程序绘制，代码由开发者借助AI编程工具实现。最终作品来自真实对局墨斑；系统从64类本地参数构图中筛选并求解墨斑高度及展示相机，没有调用在线图像生成，也不是预先绘制一张作品替换对局原画。

AI辅助编程与AI生成位图分别说明，不以代码文件数量稀释AI美术比例。官方综合比例计算方法尚未确认，不提供无依据的总体百分比；后台要求一个数字时须先核对其统计口径。本版本不以“AI美术低于50%”为依据主张最佳美术奖资格。

## 第三方与声音

wood.wav使用两项录音进行组合/处理，2026-10-20已重新核对原作者页面，两项均标明CC0 1.0：
- Yoyodaman234，Bamboo Creaking in Wind：https://freesound.org/people/Yoyodaman234/sounds/335891/
- abstraktgeneriert，Sticks.wav：https://freesound.org/people/abstraktgeneriert/sounds/348959/

paper.wav为程序建模音效；开火、移动、受伤等由Web Audio合成。没有额外购买的字体文件，使用设备系统字体。

## 外部视频处理

此前测试版含用户提供《涌现》短片及截帧封面。用户本轮未确认自制或公开分发授权，故参赛21版已将二者移出包体；首次结算只保留原创逐句提示和收束，不播放该片。旧测试包不是本次商店上传包。
