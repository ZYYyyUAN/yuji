# 余迹 · Yuji

> 各自争胜，共同留痕。

![余迹宣传插画](docs/media/cover.jpg)

《余迹》是一款围绕“涌现”创作的单机游戏：玩家与机器人各自争胜，一局结束后，对局留下的墨迹成为可以旋转观察和导出的作品。已上线 TapTap，本仓库整理最终交付版本的四端源码，用于展示工程实现。

封面为 AI 辅助生成的宣传插画，非实机截图。

## 技术实现

- **JavaScript / Canvas**：实现固定步长对局模拟、绘制、输入和作品浏览，核心逻辑与平台接口分离。
- **几何与计算调度**：保留对局墨斑数据，从 64 类本地参数构图中筛选轮廓并求解高度；H5 使用 Worker，Tap 端使用协作式主线程调度。
- **TapTap 原生小游戏**：直接使用 `tap.*` Canvas、触控、生命周期、存储、文件系统和相册接口；没有通过 WebView 加载 H5。
- **Java / Android**：通过 WebView 加载包内页面，提供本地资源访问、图片保存和生命周期桥接。
- **Electron / Windows**：使用自定义 `yuji://` 协议、隔离的预加载桥和 IPC，提供原生图片保存、全屏和本地历史管理。
- **真机问题排查**：处理绘图接口代理异常、颜色与透明度差异，移除首页同步模拟，改用离线烘焙的封面。

具体物品轮廓来自事后的构图筛选和高度求解；不将它描述成未经塑形的战斗数据直接自发形成物体。当前玩法是本地单机，没有服务端账号、联机或跨端云存档。

## 快速体验 H5

安装 Python 3 后，在仓库根目录运行：

```sh
python -m http.server 8080 --directory web
```

浏览器打开 <http://localhost:8080>。使用本地 HTTP 服务以便 Worker、资源加载和存储在一致来源下工作。

电脑端使用 WASD / 方向键移动、鼠标瞄准、按住左键射击、Esc 暂停；触屏端使用双摇杆。每个平台的历史作品独立保存在本地。
