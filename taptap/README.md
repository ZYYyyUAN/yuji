# TapTap 原生小游戏 / 23.4

此目录是直接使用 `tap.*` API 的 Canvas 客户端，不是 H5、WebView 或 Electron 壳。入口为 `game.js`，配置为 `game.json` 和 `project.config.json`，核心算法在 `core/`，平台适配在 `src/`。

原交付使用公开 AppID `tapmcqt2skkiy4p20u`，商店 ID `988982`。其他开发者发布自己的实例时，应替换两份配置中的 AppID；AppID 不是客户端密钥。仓库不包含 Server Secret 或 Client Secret。

使用 TapTap 官方当前支持的小游戏开发和打包工具，将本目录作为代码包根目录；打包前确认横屏配置和入口。源码已包含最终音效、封面和适配后的核心文件，无需依赖历史 `work/prepare_tap23.cjs`。本次源码整理没有恢复已清理的官方打包工具或旧自动生成脚本，不应照抄历史路径。

23.4 真机已确认基础对局、双摇杆、暂停、结算、两种图片保存及重新进入后的历史 / 收藏视角。重新修改或重新打包后仍需在自己的设备与账号上验证，不能沿用旧包的验收结论。

兼容措施：优先 `ctx.createImageData`，透明颜色使用 `rgba`；针对原生透明度行为缓存带像素透明度的背景并显式恢复状态；战斗虚线使用圆弧段。首页使用离线烘焙封面，避免启动时同步模拟完整对局。

`SOURCE_MANIFEST.json` 为原交付来源追溯记录，其中历史目录名不是当前构建依赖。此公开源码快照直接维护 `core/` 中的最终文件。
